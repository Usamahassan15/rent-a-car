# Premium Car Rental Platform

A production-ready luxury car rental platform built for the Pakistan market,
featuring vehicle listings, online bookings, customer accounts, admin
management, SEO optimization, WhatsApp booking integration, and Supabase backend.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- ShadCN UI
- Framer Motion
- Supabase
- PostgreSQL
- Docker
- REST APIs

## Key Features

- Vehicle rental and booking system
- Advanced vehicle search and filtering
- Customer authentication
- User profiles and booking history
- Wishlist and saved vehicles
- Vehicle availability management
- Booking management
- Invoice generation
- Reviews and ratings
- Deals and coupon system
- WhatsApp booking integration
- Blog and FAQ management
- Admin dashboard
- SEO-friendly architecture
- Responsive design
- Multi-language support
- Role-based admin access

## Admin Features
